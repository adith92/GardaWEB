🔐 Data & security yang harus didesain pertama

  • Semua stream/segment/exports diverifikasi oleh backend API, bukan cuma tombol UI.
  • Camera VLAN terpisah, tidak membuka RTSP langsung ke internet.
  • Secret di vault/config terenkripsi, login/session/RBAC + offline license.
  • Audit mencatat permintaan biometrik dan export; face identity hanya T2+.

🔌 Hardware yang ada ≠ KAK enterprise

Rencana Threadripper 1950X, X399, 128GB UDIMM dan 4-GPU adalah prototype/procurement reference. KAK meminta server rack Xeon/EPYC ECC, NVMe OS RAID1, PSU redundant, 10GbE dan garansi onsite. Jangan diam-diam mengganti BOM KAK dengan workstation.

Salin brief pertama untuk Codex

You are implementing GARDA in the existing private repository adith92/GardaWEB. FIRST read AGENTS.md, docs/GARDA_DECISION_REGISTER_v0.3.md, docs/GARDA_TIER1_BASIC_PRD_v1.0_DRAFT.md, docs/GARDA_MASTER_FEATURE_CATALOG_v0.3.md and docs/GARDA_PUSADA_KAK_GAP_MATRIX_2026-10-08.md. Treat PRD_PMC_GARDA.md as an archived demo baseline. Do not claim T1 is KAK compliant.
TASK: propose and implement a reviewable minimal P1 slice that introduces an on-prem backend skeleton, PostgreSQL migrations, site-scoped authentication/RBAC, audit events, health endpoint and a contract-tested camera/device API placeholder. Retain current React frontend, synthetic-demo routes and tests. Distinguish DEMO vs real API state. Do not turn on face identity or Ask GARDA in T1. Use Docker Compose offline-compatible configuration with no real secrets/camera credentials. Enforce RBAC server-side for all future streams, evidence and exports. Write unit/integration/negative-permission tests, run actual tests, update technical docs and acceptance traceability. Do not deploy or claim customer acceptance. Work in a branch and open a PR for review.

Definition of Done untuk langkah P1

  • API start locally and readiness reports no fabricated camera status.
  • PostgreSQL migrations up/down tested and sample synthetic fixtures separated from production config.
  • User of site A cannot fetch camera/clip/event of site B; signed/offline licensing design captured.
  • React frontend still builds, existing demo tests pass, new backend tests pass.
  • README/doc plus security acceptance matrix updated with actual test results.
