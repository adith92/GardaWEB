Arah lab / pengembangan 13 Oktober

Host Proxmox VE direncanakan untuk VM Linux GARDA dan VM Windows yang terisolasi. Mesin Threadripper dengan 128 GB RAM dan target sampai 4 GPU adalah arah lab; model GPU tetap TBA dan alokasi GARDA/Windows memerlukan pergantian mode terkontrol. Spesifikasi server kontrak KAK PUSADA berbeda dan harus dinilai terpisah.

Batasan yang sengaja terlihat

  • Feed utama tetap bertanda SIMULASI.
  • GPU ditampilkan sebagai Future Expansion / TBA.
  • Basic tidak mengaktifkan face identity, watchlist, atau tindakan otomatis.
  • Role dan share di UI bukan pengganti authorization server-side.
